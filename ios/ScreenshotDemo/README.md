# Isolated App Store screenshot app

Follows 00Food's production-view screenshot pattern. `prepare-screenshot-demo.py` copies app sources into a temporary simulator project, injects fictional quiz history and a fixed clock, and disables service requests, persistence and Keychain access. The shipping target includes `Sources`, not this directory. Never upload the screenshot binary or install it on a physical device.

Run `python3 ios/scripts/prepare-screenshot-demo.py` from the repository root, then run XcodeGen and a simulator build in the printed directory. Install the universal `ScreenshotDemo.app` on an iPhone 17 Pro Max or iPad Pro 13-inch simulator and launch `com.00quiz.screenshots --scene SCENE`. The harness uses the shipping display name so iPad's status bar reads **00Quiz**.

Scenes: `today`, `question`, `explanation`, `completed`, `history`, `friend`, `preferences`, `setup`, `sign-in`, `onboarding`, `connections`. Add `--dark` to review any scene in dark mode. Captures use the app's existing SwiftUI screens. Fixture interests and progress are fictional and do not change production defaults. Clear old simulator status bar overrides with `simctl status_bar DEVICE clear`, then set the time to 9:41 before capture. The iPad captures were made on October 23, 2026, matching the fictional fixture day; keep the fixture clock aligned with the capture date when refreshing them. The release screenshots in `docs/appstore/screenshots` are unframed native 6.9-inch iPhone captures; `screenshots/ipad` contains native 13-inch iPad captures. Both sets are opaque PNGs. The screenshot upload script reads both ordered sets from `docs/appstore/metadata.json`.
